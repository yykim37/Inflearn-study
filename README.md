## exam_grader.py — 학점 계산기 (Lab assignment 3)

과목 수와 과목별 점수를 입력받아 평균 점수와 학점을 출력합니다.

### 실행 방법

```bash
python exam_grader.py
```

1. 총 과목 수를 입력합니다.
2. 과목별 점수를 차례대로 입력합니다.
3. 평균 점수와 학점이 출력됩니다.

### 학점 기준

| 평균 점수 | 학점 |
|---|---|
| 90 이상 | A |
| 80 이상 | B |
| 70 이상 | C |
| 60 이상 | D |
| 60 미만 | F |
